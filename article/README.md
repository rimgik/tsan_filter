# Related Work

The repository records links instead of redistributing paper copies.

- [Compiling Away the Performance and Memory Overheads of Dynamic Data Race Detection](https://arxiv.org/abs/2512.05555)
- [Instrumentation Bias for Dynamic Data Race Detection](https://doi.org/10.1145/3133893)
- [OCTET: Capturing and Controlling Cross-Thread Dependences Efficiently](https://doi.org/10.1145/2509136.2509519)

These systems provide context for ownership, access filtering, and the cost of
dynamic race-detection instrumentation. Their guarantees and mechanisms differ
from the one-word filter implemented here.
